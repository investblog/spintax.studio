# spintax.studio

Public product site for [Spintax Studio](https://github.com/investblog/spintax-studio),
the native Windows editor for spintax templates —
[live in the Microsoft Store](https://apps.microsoft.com/detail/9MW3CH7B530P).

The site is a small static GitHub Pages deployment: the product overview, the
Microsoft Store link, the privacy policy at
[`/privacy.html`](https://spintax.studio/privacy.html), and contact via
[`301.st/contact`](https://301.st/contact).

Since version 0.2.0.0 the product includes an optional AI draft feature — off
until turned on, connecting only to an endpoint the user configures, with the
user's own key when that endpoint requires one. The privacy policy describes
exactly what it sends and to whom.

GitHub Pages publishes this repository with the custom domain `spintax.studio`.
