# spintax.studio

Public product site for [Spintax Studio](https://github.com/investblog/spintax-studio).

The site is a small static Pages deployment. It contains the product overview, the Store
Microsoft Store link, privacy policy at [`/privacy.html`](https://spintax.studio/privacy.html), contact via [`301.st/contact`](https://301.st/contact) and
release links. The R0 product is an offline Windows editor and does not include generative AI.

GitHub Pages publishes the repository root with the custom domain `spintax.studio`.
